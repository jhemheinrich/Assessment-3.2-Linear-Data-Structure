# Assessment 3.2: Linear Data Structure

**Last Name:** CADAYONA

This project contains four separate Python programs based on the algorithms from Assessment 3.1.

## Files
- `array_program.py` – adds the letters of CADAYONA to an array and removes from the beginning.
- `linked_list_program.py` – adds the letters as linked-list nodes and removes the first node.
- `stack_program.py` – uses PUSH and POP. Stack follows LIFO (Last In, First Out).
- `queue_program.py` – uses ENQUEUE and DEQUEUE. Queue follows FIFO (First In, First Out).

## How to run in PyCharm
1. Open PyCharm.
2. Choose **Open** and select the `Assessment_3_2_Cadayona` folder.
3. Open one of the four `.py` files.
4. Right-click inside the file and select **Run**.
5. Use the menu in the Run window:
   - Enter `1` to add the letters of CADAYONA.
   - Enter `2` to remove one letter.
   - Enter `3` to display the structure.
   - Enter `4` to exit.
6. Run each of the four Python files separately.

**Important:** Each program has its own data structure and must be run separately. If you choose option 1 more than once, the letters will be added again.
